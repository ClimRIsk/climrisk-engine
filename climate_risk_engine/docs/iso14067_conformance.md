# ISO 14067:2018 — what ClimRisk LCA does and does not do

**Status: ISO 14067-aligned screening tool. Not a verified or ISO 14067-conformant CFP study, and its output must not be published as one.**

| Requirement (ISO 14067:2018) | ClimRisk LCA | Gap before a conforming CFP claim |
|---|---|---|
| Goal and scope, intended application | Declared unit and scope stated in every result | Written goal/scope statement per study |
| Functional / declared unit | Yes (e.g. 1 t cement, 1 t crude steel) | — |
| System boundary | Cradle-to-gate A1–A3 only | Use phase / end-of-life needed for a full cradle-to-grave CFP |
| Cut-off criteria | Exclusions listed in every result | Documented cut-off rule and mass/energy/impact coverage check |
| Allocation | None applied (single-product templates) | Allocation procedure for co-products (slag, fly ash, steel by-products) |
| Data quality | Pedigree-style score per flow, lognormal P5–P95 | Data-quality assessment against the standard's requirements |
| GWP | GWP100, IPCC AR6 | — |
| Fossil vs biogenic CO2 | Reported separately | — |
| Land-use change, soil carbon, delayed emissions | Not modelled | Required where relevant |
| Capture / removals | Captured CO2 shown separately | Storage permanence and accounting rules |
| Primary data | Tier 1 / published defaults unless the user enters plant data | Measured plant data for the foreground system |
| Study report | Not generated | Full CFP study report |
| Critical review | Not performed | Required before comparative or public claims |
| Communication | Output labelled "ISO 14067-aligned screening" | Claims must follow the standard's communication rules |

## Known factor limitations (surfaced in results)
- BF-BOF steel uses IPCC Tier 1 process CO2 plus electricity; worldsteel's 2023 global average for BF-BOF is 2.32 t CO2/t crude steel, so the tool typically reads low for integrated mills. A benchmark note now appears in every steel result.
- Aluminium excludes alumina refining and PFCs unless supplied; both are listed under exclusions.
- EAF and DRI-EAF routes exclude scrap / feedstock upstream unless supplied.

Source: worldsteel Sustainability Indicators 2023/2024 (https://worldsteel.org/wp-content/uploads/Sustainability-indicators-report-2023.pdf).
