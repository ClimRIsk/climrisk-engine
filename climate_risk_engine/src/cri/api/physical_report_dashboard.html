What this report covers

For each site: how the infrastructure sits (elevation, terrain, land cover, distance to water), which hazard zones it is in (river and coastal flooding, cyclone wind, slope, wildfire, heat, water stress), what its construction year means, what is likely to go wrong for that type of facility, and the physical measures to take.

It contains no financial figures. Sites are grouped by sector. Each site takes about a minute: the engine reads terrain, satellite and flood-map data live.
