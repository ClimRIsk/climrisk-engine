Fleet files for the voyage model (CSV or XLSX). Put the EU MRV (THETIS-MRV) annual report here, or your own fleet list.
Columns are matched by meaning (IMO, name, ship type, gross tonnage, total fuel consumption, distance travelled, time at sea, or fuel_kg_per_nm / daily_consumption_t + service_speed_kn).
GET /maritime/fleet shows which columns were understood and which ignored. Nothing here is shipped with the engine: no ship data was invented.
